# CO2NSULTING – Website (Version 2, Apple-Stil)

Statische Website ohne Build-Schritt. Zum lokalen Ansehen im Projektordner starten:

    python3 -m http.server 8000

und im Browser `http://localhost:8000` öffnen.

- `index.html` … `datenschutz.html` – die Seiten
- `styles.css`, `main.js` – gemeinsames Design und Verhalten
- `img/` – Fotos (WebP, zwei Größen), Bildnachweis in `img/BILDNACHWEIS.md`
- `fonts/` – Schrift Inter (lokal)
- `LAUNCH-CHECKLISTE.md` – was vor dem Livegang noch offen ist
